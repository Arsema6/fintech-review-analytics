# Notebooks

This directory contains Jupyter notebooks for exploratory data analysis (EDA), experimentation, and development.

## Structure

- `exploration/` - Data exploration and analysis notebooks
- `experiments/` - Experimental notebooks for testing new ideas

## Guidelines

- Use descriptive names with date prefixes (e.g., `2026-05-17_data_exploration.ipynb`)
- Clean up notebooks before committing to avoid large diffs
- Document findings and insights in markdown cells
- Remove sensitive data before sharing notebooks
